# NUMERIKA

Aplikasi belajar Metode Numerik interaktif (Streamlit): materi, kalkulator Newton-Raphson,
visualisasi garis singgung, kuis, dan profil pengguna.

## Menjalankan di komputer
    pip install -r requirements.txt
    python -m streamlit run app.py

Database SQLite (`numerika.db`) dibuat otomatis saat aplikasi pertama kali dijalankan.
